⚡ NexTerm

A lightweight, modular, and cross-platform terminal toolkit built with Python.

NexTerm is a collection of useful command-line utilities designed to make system management and everyday terminal tasks easier.

Built entirely with Python's Standard Library, NexTerm requires no external Python dependencies.

---

✨ Features

Tool| Description
🖥️ System Information| Display useful system and hardware information
🔐 Hash Calculator| Calculate file hashes using multiple algorithms
📄 JSON Formatter| Format and validate JSON files
📁 File Explorer| Browse directories and inspect files
🌐 Network Diagnostics| Perform basic network diagnostics

🎨 Interface

- Colorful terminal interface
- Hacker-inspired theme
- Organized interactive menu
- Lightweight design

🛠️ Built With

- Python 3
- Python Standard Library
- ANSI Escape Sequences

📋 Requirements

- Python 3.8 or newer
- Linux, Windows, or WSL
- No external Python packages required

🚀 Installation

Clone the repository:

git clone https://github.com/K1AN-M4R/NexTerm.git

Navigate to the project directory:

cd NexTerm

Run NexTerm:

python main.py

🎯 Project Goals

NexTerm aims to provide a lightweight and modular collection of terminal utilities while keeping the code simple, readable, and easy to extend.
